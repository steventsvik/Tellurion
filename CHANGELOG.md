# Changelog

What changed in each Tellurion (formerly GhosttyEXTREME) release. Work in progress collects under
**Unreleased**; at release time that heading becomes the version number, and
`./release.sh` uses the section as the release notes.

## Unreleased

- **Pictures sent to an orchestrator on Codex work after its first command.** A second command with a pasted picture failed, because Codex read the conversation's id as one more picture.
- **"@agent" with only a picture sends the picture.** It used to send nothing and drop the pasted picture; the agent now gets the picture's path, and a mention with neither words nor picture says so.
- **A PDF or SVG copied in the Finder pastes as its path.** The orchestrator's field turned any file it could render into a picture; only photos, screenshots and other bitmap images become pictures now.

## 1.8.4

A follow-up to 1.8.3: paste in the orchestrator, a way to tell the Setup Check you don't use Codex, tiles that stay above the board's agent bar when you zoom to them, and safer handling of your config files. The shipped app no longer carries its test switches.

- **Paste works in the orchestrator's command field, pictures included.** ⌘V in an orchestrator's command (and in the board's own bar) did nothing, for two reasons: the Edit menu's Paste and Copy had no shortcut, so ⌘V reached no text field, and a terminal on the board that had never had the keyboard still answered to ⌘V as if it had. Edit → Paste and Copy show ⌘V and ⌘C again, only the terminal you're typing in takes them, and text pastes where you're typing. A picture on the clipboard (a screenshot, a copied image, an image file) pastes as a thumbnail under the orchestrator's field and goes with your command: the orchestrator sees it, and an agent you @mention is told where it's saved.
- **"Codex isn't connected" can be turned off.** A `~/.codex` folder without the codex command (an editor extension leaves one, so does trying Codex once) made the Setup Check, the sidebar and the welcome window flag Codex in red for good, even for people who don't use it. The Setup Check row now has **I don't use Codex** beside **Connect Codex**, and leaving **Connect Codex** unchecked in the welcome window means the same thing. A skipped agent shows as a quiet note with a way back, and `tellurion doctor` leaves it out too. The same goes for Claude Code.
- **Zooming to a tile no longer hides its bottom under the agent bar.** Picking a tile in the board's list (or a card, a sketch, a group or a spot on the map) fitted it to the whole window, so its prompt and status line ended up behind the bar at the bottom. The board now fits and centres what you pick in the space above the bar, and bringing a tile into view keeps clear of it too, however tall the bar is at the time: with a hint, a reply or something to confirm, or hidden ([#89](https://github.com/steventsvik/Tellurion/issues/89)).
- **Setup's changes to your files are easier to undo, and failures aren't quiet.** Every rewrite of an agent's settings file, and now of `~/.zshrc` too, leaves a fresh dated backup beside it; two changes in the same second no longer overwrite each other's copy. Settings → Agents → **Remove…** takes its lines out of `~/.zshrc` even after you've re-indented or re-spaced them, and says so when the only line it finds is one it didn't write, instead of silently leaving it. The README's Security and privacy section now lists every file Tellurion writes outside itself and how to undo each one. A board that couldn't be saved, hooks that couldn't be refreshed after an update, and a system command that couldn't start are now reported in Console.app (subsystem `com.steventsvik.ghostty-extreme`) instead of being ignored.
- **The shipped app carries no test switches.** The scripted test and demo hooks that drive test copies (`GHOSTTY_EXTREME_TEST_*`, `GHOSTTY_EXTREME_DEMO`) are left out of release builds, and the release check confirms it. `GHOSTTY_EXTREME_TEST_HOME`, which keeps a test copy's files apart from yours, keeps working.

## 1.8.3

Three fixes for Boards: the orchestrator's replies, the switch back to Classic, and the Agent Map.

- **The orchestrator's replies show in full.** Its answers were cut after four lines, and only the last two or three entries stayed. The strip under the agent list now shows the latest entries whole, scrolling once they're taller than it, and a chevron on it opens the whole conversation in place of the list.
- **Switching to Classic keeps the board's drawings, groups and wiring.** Ink drawn on tiles, named groups and orchestrator wiring were dropped when the tiles moved to windows. They stay with the board now, which also stays in your open boards: pick **Board** again and move the terminals back, and each tile returns to its place with its ink, group and wires. Picking Classic in the welcome window no longer puts a terminal window in front of it.
- **The Agent Map always wakes up.** A map could sit at "0 agents" with no dots moving while agents worked in its project: it only started following them once its window said it was visible, which a window just shown can report late or never. A map on a visible window now starts right away, and one being drawn starts itself if it missed the signal.

## 1.8.2

A small follow-up to 1.8.1 for the edition switch.

- **Switching back to Classic works.** Picking **Classic** in Settings did nothing: the board stayed and no window opened. It now offers to move the board's tiles into windows, a window per project with a tab for each tile, and closes the board (its notes, sketches and maps stay saved). Agents keep running. **Keep Board** opens a window beside the board instead.

## 1.8.1

A fix release for Boards. If you tried 1.8.0 and the orchestrator or **Settings → Board** didn't seem to do anything, this is why.

- **The orchestrator works at every zoom.** Zoomed out below about 90%, its **Connect** and **Done** buttons, and the buttons, tabs and address row of web tiles, missed clicks. They land now. An orchestrator card whose wiring record was missing (from a board saved by an earlier build) also took commands silently; it mends itself now.
- **Pause all works on macOS 27.** The shell took its terminal back ("suspended") and **Resume all** then left the agents stopped. Agents now pause and resume right where they were.
- **Switching to Board moves your terminals.** Picking **Board** in Settings or the welcome window with classic windows open asks whether to move their terminals onto the board. Say yes and every tab and split becomes a tile, laid out by project, agents still running, and the emptied windows close. **Keep Windows** opens the board beside them, as before. Picking **Board** also works again after a board was closed or switched away from: it brings a board to the front every time, opening one when none is.
- **A crash and an injection in documents.** A document with thousands of nested `>` quote markers crashed the app when opened, and the title of a `[!...]` callout could put HTML into the document and its PDF. Both fixed.

Also fixed:

- The group composer was cut off on its left side with many agents installed; its **Fill all** buttons wrap now.
- An orchestrator that started two agents in one turn gave both the second one's task; ungrouping or closing a wired group left a ghost "Group 0/0" that couldn't be unwired; its messages to agents other than Claude Code and Codex flew the board to each tile and took the keyboard.
- Restarting a tile's agent dropped the tile's saved command, so it came back as a plain shell after a relaunch and lost its **NO PROMPTS** badge.
- The tiles of a collapsed group still took clicks through the strip drawn over them, and flying to a tile near the board's edge put the view off the board.
- The board's agent could hand the wrong kanban item once items had moved while it was thinking, changed the board's own folder when asked to start agents elsewhere, and shortened the command in its confirmation so a long or multi-line one could run more than was shown. The whole command is shown now, and a terminal takes one line.
- Dictation's last words replaced what you typed after stopping it, and starting it on a Mac with no microphone crashed.
- Kanban items given to the same agent could skip a column when their status changed together; items in a column that doesn't exist were counted but invisible.
- Closing a board with a media tile kept the whole board in memory.
- Test copies of the app (`GHOSTTY_EXTREME_TEST_HOME`) keep their boards out of yours.

## 1.8.0

- **Board edition.** Tellurion can now show your terminals as tiles on a board instead of tabs. Pick **Board** when you first open Tellurion, or any time in **Settings → Edition**; Classic stays the default and nothing changes unless you switch.
  - **Every terminal is a tile.** Each one is a full terminal, so Vim, full-screen apps and every agent work as they do in a tab. Drag a tile by its title bar, resize it from its corner, and arrange them however you like.
  - **Pan and zoom.** Pinch, or hold ⌘ and scroll, to zoom; drag empty space or scroll with two fingers to move around. Two fingers over a tile move the board too, unless you're working in that tile: then they scroll its terminal. ⌥⌘9 shows everything, ⌥⌘0 goes back to actual size, and double-clicking a tile's title bar zooms in on it. Zooming never resizes a terminal, so agents aren't interrupted.
  - **See who needs you.** Each tile's edge shows its agent's status: it breathes while the agent works and pulses when it needs you. The list beside the board puts agents that need you first; click one to go to it. Zoomed out, each tile shows its agent and status in large type.
  - **The board's agent.** A bar at the bottom of every board takes plain requests ("start three Claude agents, one per kanban card", "sketch the backend: API, queue, Postgres") and sets the board up: it starts agents and terminals, adds notes, checklists, kanban boards and diagrams, hands cards to agents, groups tiles and zooms to what you ask for. It runs your own Claude Code (or Codex, chosen in its conversation) with no tools of its own, so all it can do is arrange the board. Closing tiles, typing into an agent that's already running and running a command in a new terminal wait for you to confirm, and ⌘Z undoes what it added. Type @ and a tile's name to talk to that agent directly, hold Space to speak, or use the quick actions above the bar. ⌘L jumps to it, and its handle hides it.
  - **Pause and resume agents.** **Pause all** freezes every tile's agent and everything it started, so they stop using CPU and tokens mid-turn; **Resume all** carries on where they left off. The board's agent can pause just some. Paused tiles say so in their title bar. After a long pause an agent may retry its last request.
  - **Orchestrator.** A card that runs a group of agents for you. Tap **Connect** and click terminals, or a group's **Click to wire group** pill, to wire them in; glowing wires show what's connected, with a dot running along each wire while that agent works. The card lists every wired agent with its role and status (hover one to go to it or pause it), and how many are done. Give it a command and your Claude Code (or Codex) splits the work, sends each agent its part, reads what they answer when they finish, and hands out the next steps until it's done, up to a turn limit you set; **@name** sends straight to one agent. It can start new agents too ("start two reviewers"). It only messages agents: a wired terminal with no agent running is skipped, never typed into. Permission prompts still come to you, and when an agent hasn't taken its message because something is waiting in its terminal (a folder-trust or sign-in prompt), the card says so. Start one from **+ → Orchestrator…** with its agents and a first command, from a tile's menu, or by asking the board's agent.
  - **Groups.** Put tiles in a named group with a role (Frontend, Backend, Testers, Reviewers, Design, Docs, Security or General): a frame in the role's color around them, headed with its name, how many tiles and how many are working. Drag the header to move the group, drop a tile in to add it or drag it well away to take it out, click the chevron to collapse the group into a list of its agents (they keep running), and use the header's menu to message, pause, tidy, rename, ungroup or close the whole group (it asks first when agents are running). An orchestrator can wire a group like a project.
  - **Group composer.** The bar's **Group** chip opens a composer: a name, a role, up to 12 agent slots (click a slot to change its agent, or fill them all with one), a folder, a first task, and **Skip permission prompts** (off unless you turn it on; tiles started that way show a red **No prompts** badge). **Spawn** starts them all as a grid in a new group. Save the setup as a preset for the **Presets** chip, which also has a few ready-made ones, and **Spawn 4** starts four of your default agent in one click.
  - **Talk to a group.** Type **@** and pick a group (or say "@Backend …") to message every tile in it; the bar shows who it reaches first and sends when you confirm. While you dictate, the bar shows a live waveform.
  - **Agent names and tile buttons.** Agent tiles get short names (Ada, Otto, Cy…) so you can tell them apart and @mention them; rename any tile to keep your own. Every terminal's title bar has **Restart** (starts its agent again, resuming the session when it can) and **Duplicate** (the same agent and folder beside it, in the same group), and shows its agent's status in capitals.
  - **Tool palettes.** A column of tools at the board's left edge: Select, Agent (click to start one), Group, Terminal, Text, Pen, Eraser, Web, Image and Show everything, each with a key (V, A, G, T, X, P, E, W, I, F) when you're not typing in a terminal; Escape goes back to Select. A column at the right edge has Layers (everything on the board, to jump to), Tasks, files and changes, and review loops.
  - **Draw on the board.** The pen draws straight on the board, over tiles and empty space, in 8 colors and 5 widths; a stroke drawn on a tile or card moves with it, and the eraser takes whole strokes.
  - **Labels.** The Text tool puts big text on the board to name areas of it ("General Development"), in a handwritten, plain or monospaced face; drag to move, double-click to edit, right-click for size and color.
  - **Radial menu.** Right-click empty board for a ring of quick actions around the pointer: Group, Agent, Web, Image, Duplicate, and More for the full menu.
  - **Web tiles.** A browser on the board, made with the Web tool (drag a box) or the radial menu: tabs, back and forward, an address bar that also searches, and a start page listing the localhost servers running now. Size it to a real screen or phone (24", 27" or 32" 4K, iPhone SE to Galaxy S8+) and the page lays out at that size; **{}** opens Web Inspector under the page. Web tiles keep their cookies and storage apart from everything else, get no bridge into Tellurion, refuse downloads, and keep links that open new windows in the tile.
  - **Mission Map.** See who runs whom on a board: orchestrators, the groups they (or you) run, and every agent, joined by wires (dashed for agents you reach only with @). Filter by status (Working, Needs you, Idle, Done), search, hover to follow a node's wires, and select anything to see its status and how long it's been in it, what it belongs to, and to go there, pause it or stop it. Open it from the right-hand palette, or ask the board's agent.
  - **Documents.** Have your Claude Code or Codex write a document about a project: Project overview, Onboarding guide, Architecture, README, API reference, Data model, Security overview, or anything you ask for. Pick Quick, Balanced or Thorough (each shows how long it took last time), and watch it read the project and write a finished page, with headings, tables, code and callouts. It only reads the project, never changes it. Each document is kept in that project's library (in Tellurion's folder, not in your repo); copy it as Markdown, write it again, put it on the board as a document card, or export a PDF.
  - **Diagrams.** Have your Claude Code or Codex draw a diagram of a project (Architecture, User flow, Data flow, Components, Request lifecycle, State flow, or whatever you describe), hand-drawn in Ink or in Colorful. A placeholder shows where it'll go and "Claude is drawing" until it's done; it arrives as an ordinary sketch, with groups in their own dashed frames, so you can edit everything. Starter shapes (Flow, Steps, Decision branch, Mind map) need no model. Sketches gain a style panel (**Aa** in the sketch toolbar): color, font (sans, hand, mono, serif), size, alignment, opacity, dashed lines, a hand-drawn look, and bring forward, send backward, duplicate and delete.
  - **Accounts.** Use more than one Claude Code or Codex sign-in. Add an account in **Accounts** (right-hand palette) and Tellurion opens a tile where that CLI signs in; choose which account new tiles use, open a tile with any of them, rename or remove them. Tiles on another account show its initials in the title bar, and a tile's menu can start its agent again on another account. Each account keeps its settings and sign-in in a folder of its own; Tellurion only points the agent at it and never reads sign-in details. Claude Code may keep sign-ins in the keychain, so check with /status after switching.
  - **Projects and Home.** A board's top bar shows Home, its project (the folder's git checkout), the project's other boards as tabs (with how many agents need you on each), + for another board in the project, and Close; then how many agents are live and when your usage limit resets next. **Home** lists every project with its boards, to open one or start a new project. A chip at the bottom left shows the project's branch and changes, and opens the Git panel.
  - **Kanban columns, due dates and priorities.** Kanban boards have Backlog, To Do, In Progress and Done (existing boards move over, keeping each card where it was), and a card's menu sets a due date (Today, Tomorrow, In a Week; overdue ones show red) and a priority (Low, Med, High), shown under its text.
  - **Media tiles.** Drop video or music files on the board (or **+ → Video or Music…**) to play them in a tile, one after another, with previous, next and shuffle. They pause whenever the board's window is hidden. Markdown files dropped on the board open as document cards.
  - **Settings → Features** has switches for Web tiles, Draw on boards, Documents, Diagrams, Accounts, Mission Map and Media tiles. A feature that's off leaves the palettes and menus, and Accounts off starts every tile with your usual sign-in.
  - **Launch agents.** Start up to 12 agents and shells at once in one folder, each in its own tile, with an optional first task (sent to Claude Code, Codex, Gemini and Qwen Code). Only agents installed on your Mac are offered.
  - **Boards are saved as you go.** Tiles, where you were looking and the window are saved on every change, and boards that were open come back when Tellurion starts. Claude Code and Codex pick up their last conversation; other agents start again.
  - **Several boards, one window.** The **Boards** list in the sidebar switches between them: the board you pick takes the current one's place, which keeps running out of sight, so no tab bar covers the board. Right-click a board there to **Open in New Window** beside it, or **Delete Board…** (after asking; an open board's terminals are closed).
  - **Tellurion's tools work on a board.** Visual Fix and command history open beside the board and follow the tile you're in; the command palette (⌘P), every ⌃⌘ shortcut, the Tools menu and the sidebar's icons, Ports, Localhost, local models, usage, update and setup sections are all there. Anything that would open a new tab (new sessions, Docker, Hermes, races, hand-offs, review loops, localhost servers, local models, pull requests) opens a tile instead, beside the one it came from.
  - **Each tile has a menu.** Click its **…** button or right-click its title bar to rename it, hand off, start a review loop or race, show it on the Agent Map, open Visual Fix or command history for it, undo an agent's turn, or close it. The same menu is on its row in the list, which also answers permission prompts, shows its branch (click for the Git panel) and its review.
  - **Board agents count everywhere.** Mission Control (in classic windows), notifications (clicking one moves the board to the tile), the phone, the palette's "Focus:" and "Answer" entries, hand-off targets and "wait for agents before updating" now include agents on boards.
  - **Agent Map.** Boards are for running a project, so instead of the code editor and Mission Control they have an Agent Map: the project's files as a map, grouped by folder, with every agent working in the project on it. Each agent is a dot that moves to the file it's reading or changing, trailing the files it came through, and files it changed stay in its color for a while. Hover a file to see who touched it and when, double-click a file to open it or a folder to go into it, and click an agent to go to its terminal. Open it from the **+** menu, **Tools**, a tile's menu (**Show on Agent Map**) or ⌃⌘M; **Project** in its menu picks which project it shows.
  - **Tiles in the same project share a color.** Their borders, title bars and rows in the list take the project's color, and tiles of one project that sit together get a tinted area labelled with its name. A new terminal opens beside the other tiles of its project, so it joins their group, even when you open several at once. Drag the label to move the whole group, double-click it to zoom to it, or right-click it to tidy it. **Arrange by project** in the toolbar puts each project's tiles together (⌘Z puts them back).
  - **Smoother dragging.** Tiles follow the pointer exactly and lift while dragged. They snap into line with nearby tiles or one gap beside them (hold ⌘ not to snap), and the board scrolls when you drag a tile to its edge. A tile dropped mostly on top of another slides to the nearest free spot. Zoomed out, you can grab a tile anywhere, and clicking it zooms in. Tiles under the title bar can be grabbed too.
  - **Sketches: draw the backend on the board.** A new scratchpad tile, opened from the toolbar or by right-clicking the board:
    - **Drawing:** pen and highlighter, boxes, ellipses, decision diamonds, databases, lines, and arrows that stay attached to the boxes they connect when you move them.
    - **Labels and text:** double-click a shape or arrow to label it, or empty space to write.
    - **Editing:** select, move, resize, ⌥-drag to copy, undo, copy and paste, and system colors in three line widths. Single-letter keys pick tools (P pen, R box, B database, A arrow, T text).
    - **Pictures:** drop, paste or insert them to mark them up, or bring in a photo, scan or sketch from your iPhone or iPad with Continuity Camera.
    - **Sharing:** copy a sketch as a picture, share it, save it as a PNG, or **Send to Agent**. That hands it to an agent on the board, or to a new Claude Code or Codex tile, with what you want built.
  - **Drop things on the board.** A folder dropped from Finder opens a terminal there, and pictures open in a new sketch.
  - **Notes, checklists and kanban on the board.** Add them from the toolbar's new **+** menu, or by right-clicking the board. Hand a checklist item or a kanban card to an agent on the board, or to a new Claude Code or Codex tile. The card moves to Doing while the agent works and to Done when it finishes. Drag cards between columns.
  - **Shortcuts, Spotlight and Siri.** New actions: Open Board, New Board (for a folder), Launch Agents on a Board, New Sketch (from pictures, too), Get Sketch as Picture and Arrange Board by Project. "New sketch in Tellurion" and "Launch agents in Tellurion" work from Spotlight and Siri. Focusing a terminal from Shortcuts now moves its board to it.
  - **Drag a sketch out.** Drag a sketch's title-bar symbol into Finder, Mail or Messages to drop it as a picture.
  - Tiles you've scrolled out of view, and boards in hidden windows, stop drawing.
- **Menu bar.** A new menu bar item shows a count when agents need you, in either edition. Its menu lists every agent (those waiting first; choose one to go to it), your boards, and New Sketch, Launch Agents and New Board. Turn it off in Settings (Menu bar).
- **Fixed:** in a project deep in your folders, Claude Code's transcript path was too long to report, so the code editor couldn't follow the agent's session and an orchestrator couldn't read its answers. Long paths are now reported by session, and found from there. (Takes effect once the hooks are reinstalled, which happens with the update.)
- **Fixed:** with several agents started in one folder, the code editor could keep following another agent's session after the agent's own one was known. It now switches to the agent's own session as soon as it's reported.

## 1.7.2

- **Fixed:** the README badges are now rendered by the repo's own hourly workflow and served from GitHub, so a badge service outage can no longer leave them "invalid" or broken.
- **Fixed:** the downloaded zip could be refused by macOS ("could not verify that it is free of malware") when it was unpacked by something other than Archive Utility, such as The Unarchiver, Keka or `unzip`. The zip carried metadata files that those tools put inside the app, which broke its signature. Release zips are now made without them, and the release check unpacks the zip the plain way and runs it past Gatekeeper before anything is published.
- **Design.** A new **Design** window (Tools → Design, or "Design…" in the command palette) changes how Tellurion looks, live.
  - **Twenty templates**, each a vibe: Tellurion as shipped (ink and bronze around your own terminal colors), Catppuccin Mocha and Latte, Dracula, Nord, Gruvbox dark and light, Tokyo Night, Rosé Pine and Dawn, Kanagawa, Everforest, Solarized, Synthwave (a little see-through), Matrix, Cyberpunk, Monokai Pro, GitHub Dark, Oxocarbon and Flexoki. Click one and the terminal's colors, the sidebar and panels, the window and the cursor change at once.
  - **Customize** makes it yours: keep your own terminal colors, pick any of Ghostty's built-in themes (with search), or set the background, text, cursor, selection and sixteen ANSI colors by hand. The chrome around the terminal follows those colors on its own, with an **accent** and an **AI color** of your choosing, or every chrome color set one by one. Choose the terminal font and size, the window's opacity, blur and padding, and the cursor's shape and blink.
  - **Draw your own logo.** A 32×32 pixel editor with mirror painting, undo and starting shapes. Pixels are color roles (gold, AI, text…), so the logo recolors with the design. It replaces Tellurion's T in the new-tab splash and the tool windows, and can be the Dock icon while Tellurion runs.
  - **Save it** under Templates → Yours, and come back to it any time. **Reset** returns to Tellurion as shipped.
  - The terminal's part of a design is written to `tellurion-design.ghostty` beside your Ghostty config, which gets one `config-file` line to include it. Your config is otherwise untouched; delete that line to stop using it.

## 1.7.0

This is a big one. Tellurion now runs AI models on your own Mac, works with many more coding agents than Claude Code and Codex, and its code editor can follow several agents at once.

- **Local models.** Chat with a model that runs on your Mac: nothing leaves it, and it works offline.
  - **Every model you already have.** A new **Local models** section in the sidebar lists models from **Ollama**, **LM Studio**, a **llama.cpp** or **MLX** server (`llama-server`, `mlx_lm.server` on 127.0.0.1:8080), and **Apple's on-device model** on Macs with Apple Intelligence, which needs no download. Each one shows which app serves it.
  - **Open one where you work.** Click a model to open a chat below the one you're in, or in its own tab when you're not in a chat. Or drag it onto any chat to open it underneath that one, in the same project.
  - **A chat that stays out of the way.** Replies stream in. A model that reasons before answering shows a one-line "Thinking… 12s"; `/think` shows its reasoning, `/clear` starts over and `/exit` quits. The sidebar names the chat after its model and shows its live status.
  - **Memory back when you're done.** Closing a chat, or its tab or pane, frees the model's memory right away, unless another chat is still using it.
  - **Find and download models.** **Tools → Local models** lists the most popular models on Ollama in five sizes, Tiny to Huge. It opens on the size that suits your Mac and marks the ones too big for its memory. An **Uncensored** section lists the most downloaded abliterated and uncensored builds (Dolphin, huihui_ai's abliterated Gemma 4, Qwen, DeepSeek R1, gpt-oss and more), and can be hidden. **Download** fetches a model right in the window, with a progress bar.
  - **No background polling.** The model list is checked when it's shown, after a download or removal, when a local chat starts or ends, and when you come back to Tellurion. The Mac's memory is read once.
  - **From a terminal:** `tellurion local <model>`, or `tellurion local --provider lmstudio|openai|apple …`.
- **The code editor follows every agent in a tab.** With two (up to four) agents in one tab's splits, the editor follows all of them: the code view splits into equal panes, one per agent, each showing the code its agent is reading or changing; the map shows each agent as its own comet in its brand color; and the timeline tags each agent's prompts and actions with its name. Focusing another agent's pane no longer restarts the timeline.
- **Live activity for every agent.** The editor's live feed and map used to show only Claude Code and Codex. ## 1.5.0

**Set up in a minute**
- A welcome window on first launch finds Claude Code, Codex and the tools the hooks need, connects your agents in one click, lets you pick features, and runs a live test. It only appears when something needs setting up; open it any time from the GhosttyEXTREME menu.
- The agent hooks now come inside the app. Setting up copies them to `~/.ghostty-extreme`, adds GhosttyEXTREME's entries to `~/.claude/settings.json`, `~/.codex/hooks.json` and `~/.zshrc` (each backed up first, your own hooks untouched), and a rebuilt app keeps installed hooks up to date. No more separate hooks download or `install.sh`.
- **Check Setup** (GhosttyEXTREME menu or ⌘P) checks the hooks, each agent's config, jq, the shell integration, notifications and recent hook errors, with a fix button on each problem. **Copy report** gives a plain-text report for GitHub issues.
- `ghostty-extreme doctor` runs the same checks in a terminal and sends a test event through the real hooks.
- The sidebar shows a warning when agent status needs fixing, and a confirmation when a live test arrives.

**Settings**
- **GhosttyEXTREME Settings** (⌃⌘,) turns each feature on or off: code editor, Visual Fix, Mission Control, races, localhost sessions, review, undo, command history, activity, Background, the usage meter, Ports and the Git panel. A feature that's off has no menu item, shortcut, button or palette entry, and does no background work. Presets: Everything, Agent essentials, Just the sidebar.
- Animation (Full or Status only), aurora, compact rows and sidebar width, plus removing the hooks again.

**Ports**
- A Ports section in the sidebar lists what's listening and which project it belongs to (Next.js, Vite, Django and more get their own badge). Open it in the browser or Visual Fix, click it to go to its tab, or **Stop** it (click twice). Apps and container ports are one click away.
- When a command fails because its port is taken ("EADDRINUSE", "address already in use"), the sidebar names what holds the port and offers to stop it.
- The list reads sockets straight from macOS, so it costs a couple of milliseconds every few seconds, and nothing while GhosttyEXTREME is in the background.

**Git panel**
- Click a tab's branch in the sidebar for a panel with its pull request (title, review state and every check, failing ones first, each linked to its log), branches (switch, filter, create), stashes (stash, apply, pop, drop) and recent commits.
- Tabs show commits to push and pull (↑2 ↓1) and the branch's pull request with its checks (#123 ✓) beside the branch.
- Pull requests come from the GitHub CLI (`gh`) when it's installed and signed in, refreshed every minute and when an agent finishes a turn. Switching branches warns when an agent is working in the tab and offers to stash uncommitted changes first.

**Agents working together**
- **Hand Off…** (⋮ menu, Mission Control, ⌘P) passes a pane's work to another agent with what it needs: the task, the recent conversation, exactly what the first agent changed (a diff since its first prompt, from the undo snapshots) and failed commands. Review, continue, or ask for a second opinion; to a new Claude Code or Codex beside it, or to one that's already running. You can read and edit the message first.
- **Review loops**: pair an agent with a reviewer (⋮ → Start a review loop…). When the writer finishes a turn, the reviewer gets its changes and answers APPROVED or CHANGES NEEDED; its findings go back to the writer, round after round, until it approves or the round limit (3 by default). Each message waits for you to press Send on the agent's card, unless you turn on Send automatically.
- **Send a failed command to the agent already working on the project**: the failed-command chip offers it first, with the output and what's changed.
- Messages are only ever typed into an agent between turns, into an empty input box: never into a permission prompt, a menu or a dialog, and never over something you've started typing (greyed-out suggestions don't count). Until then they wait on the agent's card, where you can drop them.

**Install and update**
- **One-line install**: `curl -fsSL https://raw.githubusercontent.com/steventsvik/Tellurion/custom/install.sh | bash` downloads the latest release, checks its checksum and puts it in /Applications, with no quarantine step.
- **Updates in the app**: GhosttyEXTREME now checks its own releases (GhosttyEXTREME → Check for Updates…, and automatically) and installs them. Updates are signed with this project's key and nothing else is accepted.
- **Fixed**: Check for Updates… used official Ghostty's feed, which could offer plain Ghostty and replace GhosttyEXTREME ([#13](https://github.com/steventsvik/Tellurion/issues/13)). Coming from 1.4.x, install this version once with the line above; later versions update in the app.
- Releases are signed with the same certificate every time, so macOS keeps your permissions (notifications, folder access) across updates.

**Every shortcut at a glance**
- Hold ⌃⌘ for a moment to see every ⌃⌘ shortcut over the window, along with Ghostty's essentials; let go and it's gone. ⌃⌘/ keeps it open.

**Answer permission prompts from anywhere**
- **Allow** and **Deny** on an agent's permission prompt, from its sidebar card, Mission Control or the notification, without switching to its pane.
- Keys are only sent when the pane is showing Claude Code's or Codex's prompt with the first "Yes" selected, so a status that's a moment out of date can't send a stray Enter or Escape.

**Undo an agent's turn**
- Every agent turn starts with a snapshot of the project. Undo the last turn (or an earlier one) from the tab's ⋮ menu, or with **Restore to before this** on any prompt in the agent timeline.
- Restoring lists every file it will change and asks first; Return cancels. Your current files are saved before a restore, so you can undo the restore too.
- Snapshots are git objects written through a copy of the index: no commits, branches or stash entries, and your staged changes are untouched. Folders that aren't repositories work too.

**Lighter**
- Each tab's code editor is only created when you first open it, and freed when you close it and its agent has exited. Before, every tab with an agent kept a hidden editor (a separate WebKit process) in the background.

**Calmer terminal frame**
- The light racing around the terminal's edge is gone. The corners breathe while an agent works and pulse smoothly when one needs you.
