Boards.

Your agents, on one board you can see, steer and hand work to. Pick Board when you first open Tellurion, or any time in Settings → Edition. Classic stays the default. Drag the slider above to compare.

  • Every terminal is a tileA full terminal, so Vim and every agent work as in a tab. Zoom, pan, and double-click a tile to fly to it.
  • See who needs youTile edges breathe while agents work and pulse when they need you. Allow and Deny from the list.
  • Spin up a teamUp to 12 agents at once from the Group composer or a preset, with one first task for all of them.
  • OrchestratorA card that runs a group for you. Tap Connect, wire in agents, give it a command. Mission Map shows who runs whom.
  • The board's agentAsk in plain words and it sets the board up. Type @ to message one agent or a whole group.
  • And moreWeb tiles, the Agent Map, kanban you hand to agents, sketches and diagrams, and Pause all to freeze every agent mid-turn.

All of the sidebar’s animation runs in Core Animation, and anything you can’t see pauses — background tabs, hidden and minimized windows. Measured on an Apple silicon MacBook. This page plays by the same rules: every loop stops when it leaves your screen.

Nothing leaves your Mac

No account, telemetry or server. Agent tracking and shared memory read the files Claude Code and Codex already write.

Only your own hooks can talk to it

Agent status arrives as escape sequences any printed text could imitate — so each launch creates a secret only its own terminals and hooks know. Events without it are ignored.

No credentials, ever

The Backend view runs your providers’ own CLIs with their existing logins, read-only commands only. It reads the names of your env variables, never their values.

The editor stays local

It can only show its own pages, and Visual Fix only talks to your local dev server.

Install in a minute

~ — zsh — 80×14
❯
downloading Tellurion 1.7.1 … done
verifying SHA-256 checksums … ok
✓ Tellurion.app installed — opening the welcome window
curl -fsSL https://raw.githubusercontent.com/steventsvik/Tellurion/custom/install.sh | bash
  1. Run the one-liner. It downloads the latest release, checks it against the release’s SHA-256 checksums, and puts Tellurion.app in /Applications.
  2. Open it. The welcome window finds Claude Code and Codex, connects them in one click (backing up each file it changes), and runs a live test. Check Setup re-verifies everything later, with a fix button on each problem.
  3. That’s it. Updates arrive in the app, signed with this project’s key — nothing else is accepted. Your existing Ghostty configuration works as-is.
Installing by hand instead

Download Tellurion-<version>-macos-arm64.zip from the latest release, unzip it and move Tellurion.app to /Applications. It’s signed with a Developer ID and notarized by Apple, so it opens like any other download.

Requires an Apple silicon Mac on macOS 13 or newer. To build from source, see the build instructions.
